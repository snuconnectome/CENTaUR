# EXAONE × Ko-CENTaUR: Mind–Brain 통합 한국형 파운데이션 모델 구축

- **작성일**: 2025년 10월 7일
- **주관**: 서울대학교 AI연구원 디지털정신건강연구소, LG AI연구원 EXAONE 팀
- **책임자**: 차지욱 (SNU), *(LG 측 책임자 지정 예정)*

---

## 1. 비전 및 연구 목표

- EXAONE-3.0-32B를 기반으로 한국어 행동·발달 데이터를 학습한 “mind and behavior foundation model”을 구축하고, 추후 뇌 영상 기반 파운데이션 모델과 정렬해 통합적인 정신건강 AI 스택을 마련한다.
- 발달 궤적 예측, 증상 변화 추적, 치료 반응 예측 등 임상 의사결정을 지원하는 reasoning layer를 개발한다.
- 전국 정신건강 연구기관이 대규모 AI를 책임감 있게 활용할 수 있도록 재현 가능한 파이프라인과 거버넌스 표준을 확립한다.

---

## 2. 협업 구조

- **운영위원회**: SNU 디지털정신건강연구소, LG AI연구원 EXAONE 리더십, 정신의학·뇌과학 자문진으로 구성.
- **실무 워킹그룹**
  1. 모델 엔지니어링: EXAONE 미세조정, 증류, 추론 최적화
  2. 행동 데이터 통합: ETL, 메타데이터 정책 검증, 코호트 정합
  3. Mind–Brain 정렬: 행동 잠재공간과 신경영상 임베딩 매핑
  4. 컴플라이언스·윤리: IRB/DUA, 개인정보 보호, 모형 카드 작성
- **데이터 보안**: 서울대학교 GPU 클러스터 내 보안 구역 운영, VPN 기반 EXAONE 공동 연구 환경 구성, 접근 로그 관리.

---

## 3. 데이터 자산 및 확보 계획

- **발달 코호트**: 한국 아동발달 연구, Seoul Child Emotion Lab 자료, 교실 기반 행동 관찰 등 약 2,500명 규모.
- **임상 코호트**: 기분·불안 클리닉(n≈800), ASD/ADHD 클리닉(n≈600), 초발 정신증 프로그램(n≈400), 수면·EMA 데이터(n≈300). CBCL/WISC/KSADS 요약 지표만 수집.
- **예정된 뇌영상 파트너**: 서울대병원 청년 fMRI 코호트(n≈300), EEG 주의집중 데이터(n≈200), 확산 MRI(선택).
- **거버넌스**: 2025년 10월 28일까지 IRB 제출, 2025년 12월 12일 승인 목표. 표준 DUA 양식으로 사용 목적, 보존 기간, 폐기 정책 명시.

---

## 4. 기술 로드맵 (12개월)

### Phase 1 (2025년 10월–2026년 1월): MVP 검증
- 레거시 CENTaUR를 `ko_centaur/` 패키지 구조로 재구성.
- EXAONE-10.8B 기반 QLoRA 벤치마크, 한국어 토크나이저 효율 보고서(2025년 11월 15일 제출).
- 메타데이터 정책(`policy.yaml`) 및 공개/비공개 LoRA 분리.
- 성과지표: 기존 작업 대비 NLL ≥20% 개선, 보안 데이터 인프라 가동.

### Phase 2 (2026년 2월–2026년 5월): 확장 및 증류
- Qwen 2.5-72B reasoning trace → EXAONE-32B distillation.
- 발달 단계·진단 조건부 어댑터 도입.
- 다기관 평가 하네스 구축, 인간 규준 상관계수 r ≥0.70 달성.

### Phase 3 (2026년 6월–2026년 9월): Mind–Brain 통합
- 행동 임베딩과 fMRI/EEG 임베딩 간 대조 학습.
- DeepSeek-R1 등 reasoning 엔진 하이브리드 적용.
- 규제·윤리 검증 포함 모델 카드 제작, 2개 병원 파일럿 실시.

## 5. 자원 및 컴퓨팅 요구

- GPU: SNU 클러스터 A100 80GB 4대 이상, LG 측 EXAONE 최적화 지원 및 추가 컴퓨팅 크레딧 협의.
- 스토리지: 암호화 및 역할 기반 접근 제어를 갖춘 150TB.
- 인력: SNU 전임연구원 5명, 포닥 3명, 대학원 RA 4명, LG AI연구원 엔지니어 협업.

## 6. 공동 성과물

- 2026년 3월 공동 백서: 한국형 Mind Foundation Model 청사진.
- 공개 벤치마크 세트(비민감 테스트)로 EXAONE 행동 추론 시연.
- 비공개 민감 데이터 기반 모델 가중치(상호 NDA/DUA 하 관리).
- 한국 정신건강 임상 적용 로드맵(규제, 파일럿 프로토콜 포함).

## 7. 위험 관리 및 준수 전략

- 개인정보 보호: Private LoRA 차분프라이버시 옵션, CBCL/WISC/KSADS 항목 텍스트 저장 금지, 메타데이터 자동 검사기 구축.
- 안전성: 민감 문항 회상 여부를 탐지하는 프로빙 시나리오, 임상용 설명 가이던스 정기 점검.
- 거버넌스: 분기별 운영위 검토(2026년 1월 31일, 2026년 5월 31일, 2026년 9월 30일)로 목표 달성 여부와 준수 사항 확인.
