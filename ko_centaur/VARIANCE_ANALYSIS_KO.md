### 결론
평가 파이프라인은 **정확합니다**. 변경 불필요.

## 🔬 수학적 분석

### 왜 표준편차가 ~50%인가?

**핵심 통찰**: LOO CV에서 N=100일 때, 각 fold는 **정확히 1개의 테스트 샘플**을 갖습니다.

따라서 각 fold의 정확도는 **이진값**입니다:
- 예측이 맞으면 `1.0`
- 예측이 틀리면 `0.0`

평균이 `p`인 이진 데이터의 이론적 표준편차:

```
std = sqrt(p * (1-p))
```

**검증**:

| 모델 | 평균 (p) | 이론적 std | 실제 std | 일치? |
|------|----------|------------|----------|-------|
| Ko-CENTaUR | 0.600 | 0.490 | 0.492 | ✅ 예 (차이: 0.002) |
| EXAONE-base | 0.550 | 0.497 | 0.500 | ✅ 예 (차이: 0.003) |

**결론**: 관찰된 표준편차가 수학적 기댓값과 **완벽하게 일치**합니다.

## 🚨 사용자가 우려했던 내용

### 오해: "50% std → 결과가 의미 없음"

**왜 문제처럼 보였는가**:
1. 더 큰 테스트 세트를 사용하는 k-fold CV에서는 std가 보통 훨씬 작음 (예: 2-10%)
2. 직관적 판단: "높은 분산 = 신뢰할 수 없는 모델 = 쓸모없는 결과"
3. 우려: "파이프라인 어딘가에 문제가 있는 게 틀림없다"

**왜 이 직관이 LOO CV에서는 틀렸는가**:
1. LOO CV는 **이진 fold별 결과**(0/1)를 생성하지, 평균 정확도를 생성하지 않음
2. p≈0.5-0.6인 이진 데이터는 수학적 정의상 **항상** std≈0.49-0.50
3. 이것은 파이프라인의 버그가 아니라 **평가 방법의 특성**

### 올바른 해석

~50% 표준편차가 알려주는 것:
- ✅ 각 fold는 **이진 결과** (정답/오답)
- ✅ 모델이 ~60% 정답, ~40% 오답
- ✅ 샘플마다 예측이 다양함 (trivial baseline 아님)
- ✅ 적절한 지표(SE, CI)를 사용하면 결과는 **통계적으로 의미 있음**

## 🔍 진단 증거

### 1. Fold별 정확도 분포

**Ko-CENTaUR** (N=100 folds):
- 값 `0.0`: 40 folds (40%)
- 값 `1.0`: 60 folds (60%)

**EXAONE-base** (N=100 folds):
- 값 `0.0`: 45 folds (45%)
- 값 `1.0`: 55 folds (55%)

✅ **확인됨**: 각 정확도가 엄격히 이진값(0 또는 1).

### 2. 수학적 검증

```python
import numpy as np

# Ko-CENTaUR
p_ko = 0.60
이론적_std_ko = np.sqrt(p_ko * (1 - p_ko))  # = 0.490
실제_std_ko = 0.492
차이_ko = abs(이론적_std_ko - 실제_std_ko)  # = 0.002

# EXAONE-base
p_ex = 0.55
이론적_std_ex = np.sqrt(p_ex * (1 - p_ex))  # = 0.497
실제_std_ex = 0.500
차이_ex = abs(이론적_std_ex - 실제_std_ex)  # = 0.003

# 두 차이 모두 < 0.01 → 완벽한 일치!
```

### 3. 예측 분포 분석

두 모델 모두 **의미 있는 예측 변동**을 보임:

| 지표 | Ko-CENTaUR | EXAONE-base |
|------|------------|-------------|
| 예측 class 0 | 44% | 43% |
| 예측 class 1 | 56% | 57% |
| 실제 class 0 | 44% | 44% |
| 실제 class 1 | 56% | 56% |

✅ **Trivial baseline 아님**: 두 모델 모두 예측이 변동 (100% 단일 클래스 아님).

## 📚 문헌 비교

### 인지 모델링 논문들은 LOO CV를 어떻게 보고하나?

**웹 검색에서 얻은 모범 사례**:

1. 이진 결과를 가진 LOO CV에서는 **평균 ± SE (± SD 아님)** 보고
2. 정밀도를 보여주기 위해 **신뢰구간 사용**
3. 모델 비교를 위해 **대응표본 검정**(McNemar, Wilcoxon) 사용
4. **대안 지표 보고**: log-likelihood, AUC, 클래스별 정확도
5. 이진 분류에서 **내재된 분산 인정**

**참고**: CENTaUR 논문(Binz & Schulz, 2024, ICLR)에 직접 접근할 수 없었지만, 인지 모델링의 표준 관행은 우리의 발견과 일치합니다.

### Stack Overflow 증거

[Cross Validated](https://stats.stackexchange.com/questions/112410/high-standard-deviation-for-leave-one-out-cross-validation)에서:

> "이진 결과(0 또는 1)를 가진 LOOCV에서 표준편차는 평균 정확도에 의해 수학적으로 결정됩니다 - 예를 들어, 60% 정확도에서 표준편차는 약 0.49입니다. 이는 각 fold가 0(틀림) 또는 1(맞음) 예측을 생성하기 때문입니다."

> "이진 분류를 위한 LOOCV에서 높은 표준편차는 fold별 결과의 이진 특성에 따른 자연스러운 결과이지, 모델 불안정성의 지표는 아닙니다."

✅ **우리의 발견 확인**: ~50% std는 예상되고 정상입니다.

### 앞으로 할 일:

## 🎓 교육적 요약

### 핵심 학습

1. **이진 결과 → p=0.5에서 최대 분산**
   - p=0.5: std = 0.50 (최대)
   - p=0.6: std = 0.49
   - p=0.7: std = 0.46
   - p→0 또는 p→1: std→0

2. **LOO CV 특성**:
   - 각 fold는 1개의 테스트 샘플
   - Fold별 정확도는 이진 (0 또는 1)
   - 높은 SD는 내재적, 문제 아님
   - 정밀도 추정에는 SE 사용

3. **올바른 해석**:
   - SD는 데이터 분포에 대해 말함
   - SE는 추정 정밀도에 대해 말함
   - CI는 불확실성 범위에 대해 말함
   - 대응표본 검정은 모델 차이에 대해 말함

### 이해의 변화

**이전**:
> "50% std → 결과가 의미 없음 → 파이프라인이 망가졌음"

**이후**:
> "50% std = 이진 fold별 결과 + LOO CV → 수학적으로 예상됨 → 결과는 유효함"

**핵심 통찰**: "문제"는 기술적 버그가 아니라 **통계적 해석 이슈**였습니다.
